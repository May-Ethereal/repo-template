# Contributing

Contributions follow the organization-wide guidelines:
<https://github.com/May-Ethereal/.github/blob/main/CONTRIBUTING.md>

In short:

1. Open an issue first for anything larger than a bug fix, so the approach is
   agreed before the work starts.
2. Work on a branch named `feat/…`, `fix/…` or `chore/…`.
3. Keep the pull request focused, and describe how the change was verified.
4. One approving review is required before the merge.
5. Never commit secrets, release binaries or build output.

The [Code of Conduct](https://github.com/May-Ethereal/.github/blob/main/CODE_OF_CONDUCT.md)
applies to every interaction in this repository.
